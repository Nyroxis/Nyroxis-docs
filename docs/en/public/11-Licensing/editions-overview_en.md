# Licensing Model

Nyroxis offers a simple, transparent licensing model — no subscription traps, no hidden data collection, and no dependency on external servers for platform operation.

---

## How Licensing Works

Every Nyroxis license is bound to the user's hardware through a unique HWID-derived identifier.
A cryptographic key is generated from the same hardware profile, creating a license that is:

- **Non-transferable** — tied to the specific device it was issued for (up to 3 device activations per license key)
- **Tamper-resistant** — any modification is detected immediately by Nyroxis System Guardian
- **Offline after activation** — once activated, validation requires no ongoing internet connection

## What Is Never Included

- No telemetry sent to Nyroxis or any third party by the core platform
- No behavioral data collected for licensing purposes
- No dependency on internet connectivity for platform operation
- No hidden costs tied to data volume or event counts

> **Important — data and hardware changes:** Because encryption keys are bound to the device hardware, a major hardware change or OS reinstallation can change the device identity and make previously encrypted data unreadable. This is disclosed in the license terms.
