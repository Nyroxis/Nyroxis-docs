# Licensing Model

Nyroxis offers a simple, transparent licensing model — no subscription traps, no hidden data collection, no dependency on external servers.

---

## How Licensing Works

Every Nyroxis license is bound to the user's hardware through a unique HWID-derived identifier.
A cryptographic key is generated from the same hardware profile, creating a license that is:

- **Non-transferable** — tied to the specific device it was issued for
- **Tamper-resistant** — any modification is detected immediately by Nyroxis System Guardian
- **Fully offline** — validation requires no internet connection, no external server
