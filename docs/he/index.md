# מהי Nyroxis?

Nyroxis היא פלטפורמת אבטחת סייבר קלה ומסייעת בינה מלאכותית, שתוכננה להגן על **נקודות קצה אישיות ולא מנוהלות** — המכשירים שכלי האבטחה הארגוניים המסורתיים לרוב מתעלמים מהם.

היא מספקת ניטור רציף המעמיד פרטיות בראש, ומביאה זיהוי ברמת SOC למכשירים אישיים, ללא צורך בקישוריות ענן, מומחיות טכנית או תשתית ארגונית.

## מדוע Nyroxis קיימת

מתקפות סייבר מודרניות כבר אינן מכוונות רק כלפי חברות. מנהלים, עורכי דין, שופטים, רופאים, עיתונאים ואפילו משפחות מותקפים על **המכשירים האישיים שלהם** — שם אין SOC, אין SIEM ואין צוות אבטחה שישמור עליהם.

Nyroxis ממלאת את הפער הזה על ידי הבאת **נראות וזיהוי ברמה ארגונית** לרמה האישית — בשקט, באופן מקומי, וללא פשרות.

## למי מיועדת Nyroxis?

- מנהלים ואנשים בעלי פרופיל גבוה
- עורכי דין, שופטים, רופאים ואנשי מקצוע המטפלים בנתונים רגישים
- משפחות המחפשות נראות אבטחה דיגיטלית
- מהנדסי אבטחת סייבר ואנליסטי SOC בבית
- נוסעים תכופים ועובדים מרחוק
- קבלנים עצמאיים ויועצים

## כיצד Nyroxis פועלת (סקירה כללית)

Nyroxis בנויה סביב ארבעה רכיבים מרכזיים הפועלים יחד:

### Nyroxis Agent
- ניטור שקט ורציף ממספר ערוצי מערכת
- מנרמל, מצפין ומאחסן הכל באופן מקומי
- פועל באופן לא מקוון לחלוטין — עיצוב עמיד בפני חבלה
- ~57 MB זיכרון RAM, 0.1% מעבד

### Nyroxis Intelligence
- מנוע זיהוי תלת-שכבתי
- 27 כללי זיהוי, 12 כללי מתאם, 2 כללי שרשרת (גדל ברציפות)
- ניתן להרחבה על ידי אנשי אבטחה — כללים מותאמים אישית בפורמט JSON
- ~87 MB זיכרון RAM, 1.8% מעבד

### Nyroxis System Guardian
- שומר שקט במגש המערכת
- מנטר את כל השירותים כל 3 שניות
- מנהל גיבויים, אימות רישיון לא מקוון ובדיקת עדכונים
- עוצר שירותים אוטומטית אם הרישיון פג
- ~6.5 MB זיכרון RAM, 0.1% מעבד

### Nyroxis Dashboard
- נראות בזמן אמת על אירועים, זיהויים, מתאמים ושרשראות
- חיפוש פורנזי, ניתוח בינה מלאכותית/ML, דיווח PDF/CSV
- אנגלית, צרפתית וגרמנית

```
[ מכשיר ]
   |--> Nyroxis Agent          (איסוף והצפנה)
   |--> Nyroxis Intelligence   (זיהוי ומתאם)
   |--> Nyroxis System Guardian (ניטור והגנה)
   |--> Nyroxis Dashboard      (נראות וניתוח)
```

## יתרונות מרכזיים

- כל הנתונים נשארים על המכשיר שלך — תמיד
- אחסון מוצפן ברמה פורנזית (AES-256)
- 27 + 12 + 2 שכבות כללי זיהוי, ניתנות להרחבה על ידי אנשי אבטחה
- זיהוי אנומליות מקומי באמצעות בינה מלאכותית/ML — ללא ענן, ללא טלמטריה
- רישוי לא מקוון מבוסס HWID
- קל ושקט — בלתי נראה לתוקפים
