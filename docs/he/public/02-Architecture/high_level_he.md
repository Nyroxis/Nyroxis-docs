# סקירת ארכיטקטורה

Nyroxis בנויה על ארכיטקטורה קלת משקל המכוונת לפרטיות, שתוכננה לספק נראות וזיהוי ברמה ארגונית מבלי להסתמך על הענן.
המערכת פועלת באופן מלא במכשיר המשתמש ומורכבת מארבעה רכיבים עצמאיים הפועלים יחד באופן מאובטח.

---

## רכיבים מרכזיים

### 1. Nyroxis Agent
מנטר נקודת קצה קל משקל שמבצע:
- איסוף אירועים רלוונטיים לאבטחה ממספר ערוצי מערכת
- נרמולם והצפנתם מיידית בעת הלכידה
- אחסון הכל במסד נתונים מקומי עמיד בפני חבלה
- פעולה 100% לא מקוונת — ~57 מגה-בייט RAM, ~0.1% CPU

### 2. Nyroxis Intelligence
מנוע זיהוי וקורלציה במהירות גבוהה שמבצע:
- הפעלת 27 כללי זיהוי על אירועים בודדים
- הרצת 12 כללי קורלציה על אירועים קשורים לאורך זמן
- הרצת 2 כללי שרשרת לזיהוי רצפי תקיפה רב-שלביים
- הפעלת התראות מיידיות בכל התאמה לכלל
- קבלת כללים מותאמים אישית מאנשי אבטחה
- ~87 מגה-בייט RAM, ~1.8% CPU

### 3. Nyroxis System Guardian
שומר שקט בשורת המשימות שמבצע:
- ניטור Nyroxis Agent ו-Intelligence כל 3 שניות
- ניהול גיבויים ואימות רישיון מבוסס HWID (מקומי לחלוטין)
- בדיקת עדכונים אוטומטית
- עצירה אוטומטית של שירותים אם הרישיון פג
- ~6.5 מגה-בייט RAM, ~0.1% CPU

### 4. Nyroxis Dashboard
ממשק ברור ואינטואיטיבי שמבצע:
- הצגת אירועים, זיהויים, קורלציות ושרשראות
- מתן חיפוש פורנזי, תרשימים ודוחות PDF/CSV
- כולל מנוע AI/ML מקומי (Isolation Forest + ניתוח סטטיסטי)
- תמיכה באנגלית, צרפתית וגרמנית

## זרימת נתונים ברמה גבוהה

```
[ אירועי מערכת ]
        ↓
[ Nyroxis Agent ]          ← איסוף, נרמול, הצפנה
        ↓
[ מסד נתונים מקומי מוצפן ] ← AES-256, SQLite, מקושר בהאש
        ↓
[ Nyroxis Intelligence ]   ← 27 זיהוי + 12 קורלציה + 2 כללי שרשרת
        ↓
[ Nyroxis Dashboard ]      ← נראות, AI/ML, פורנזיקה, דיווח
        ↑
[ Nyroxis System Guardian ] ← מנטר, מגבה, מאמת רישיון
```

בשום שלב אין יומנים או נתונים רגישים המועלים לשרתים חיצוניים.

---

## עקרונות עיצוב

### פרטיות כעיקרון מנחה
- אין קליטת נתונים בענן
- הצפנה מקומית בעת הלכידה
- המשתמש שומר על שליטה מלאה בכל עת

### שלמות פורנזית
- יומנים מוצפנים AES-256
- בלוקי אירועים מקושרים בהאש
- אחסון עמיד בפני חבלה המתאים להליכים משפטיים

### פעולה קלת משקל
בנויה לפעול בצורה חלקה על מחשבים ניידים ותחנות עבודה אישיות מבלי לפגוע בפרודוקטיביות היומיומית.

### אבטחה מקומית עדיפה
אין צורך בחיבור לאינטרנט עבור:
- ניטור וזיהוי
- ניתוח AI/ML
- שימוש ב-Dashboard
- אימות רישיון

### יכולת הרחבה
אנשי אבטחה יכולים לכתוב ולפרוס כללי זיהוי, קורלציה ושרשרת מותאמים אישית מבלי לשנות את המערכת המרכזית.

---

## סיכום
Nyroxis מספקת ארכיטקטורה מודרנית, מודולרית ומוצקה פורנזית המביאה נראות וזיהוי ברמה מקצועית למכשירים אישיים — לחלוטין ללא חיבור לאינטרנט, תוך כיבוד מלא של פרטיות המשתמש.
