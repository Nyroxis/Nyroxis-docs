# Nyroxis Agent — סקירה כללית

ה-Nyroxis Agent הוא רכיב הניטור והאיסוף המרכזי של הפלטפורמה.
הוא פועל באופן מקומי על מכשיר המשתמש, אוסף ומנרמל בשקט אירועי אבטחה, מצפין אותם ומאחסן אותם במסד נתונים מקומי עמיד לפני חבלה — הכל עם שימוש מינימלי במשאבים.

---

## מה ה-Agent עושה

ה-Agent צופה ברציפות בפעילות המערכת ובונה ציר זמן אבטחה מובנה ומוצפן.

הוא מנטר:
- יצירה וסיום של תהליכים
- חיבורי רשת ומטא-נתוני תעבורה
- שינויי קבצים ושינויי רגיסטרי
- פעולות הרשאות וניסיונות גישה לאישורים
- אירועי מערכת ואבטחה (Windows Event Logs)
- הרצת PowerShell וסקריפטים

כל האירועים נאספים **באופן פרטי ומקומי** — שום דבר אינו מועבר לגורמים חיצוניים.

---

## צינור האיסוף

1. **איסוף** — אירועים נקלטים ממספר ערוצי מערכת בו-זמנית
2. **נרמול** — נתונים גולמיים מועשרים ומתוקננים עבור מנוע הזיהוי
3. **הצפנה** — המטען מוצפן עם AES-256 לפני כל פעולת כתיבה
4. **אחסון** — אירועים מוצפנים נכתבים למסד הנתונים המקומי SQLite
5. **הזנה** — נתונים זורמים ל-Nyroxis Intelligence להערכת כללים בזמן אמת

---

## פעולה המכוונת לפרטיות

ה-Agent לעולם אינו מעלה יומנים או שולח נתוני אירועים לשרתים חיצוניים.
הכל נשאר על המכשיר והוא:
- מוצפן ברגע האיסוף
- מוגן מפני חבלה באמצעות בלוקי אירועים המקושרים בחשיש
- מאוחסן במסד נתונים מקומי מאובטח SQLite
- תחת שליטתו הבלעדית של המשתמש בכל עת

---

## קל משקל בתכנון

ה-Agent מותאם לטביעת רגל מינימלית:
- ~57 MB RAM
- ~0.1% CPU
- פעולת רקע שקטה כשירות Windows
- מתאים לפעולה רציפה על מחשבים ניידים אישיים ללא פגיעה בפרודוקטיביות היומית

---

## עמיד ומודע לחבלה

ה-Agent משלב מנגנוני הגנה כדי להבטיח:
- נתוני אירועים שנאספו אינם יכולים להשתנות או להימחק ללא זיהוי
- תוקפים אינם יכולים למחוק בשקט את פעילותם
- בלוקי אירועים המקושרים בחשיש חושפים כל ניסיון מחיקה, שינוי או הזרקה

Nyroxis System Guardian מנטר את המצב התפעולי של ה-Agent כל 3 שניות ונוקט פעולה מתקנת אם השירות נעצר באופן בלתי צפוי.

---

## פועל לחלוטין במצב לא מקוון

אין צורך בחיבור לאינטרנט עבור:
- ניטור
- נרמול והצפנה
- אחסון נתונים
- הזנת Nyroxis Intelligence

Nyroxis פועל באופן מלא בסביבות מבודדות או air-gapped.

---

## סיכום

ה-Nyroxis Agent מספק ניטור רציף, מוצפן ולא מקוון — נותן למשתמשים נראות ברמה ארגונית מבלי לחשוף את נתוניהם לצדדים שלישיים, ומספק ראיות באיכות פורנזית המתאימות להליכים משפטיים ורגולטוריים.
