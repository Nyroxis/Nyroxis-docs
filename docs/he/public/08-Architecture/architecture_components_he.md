# רכיבי הארכיטקטורה

סעיף זה מתאר כל רכיב מרכזי של פלטפורמת Nyroxis ומסביר כיצד הם פועלים יחד כדי לספק אבטחה פרטית, לא מקוונת ועמידה בפני חבלה.

---

## 1. Nyroxis Agent

שירות הרקע הקל האחראי על:
- ניטור תהליכים, חיבורי רשת, שינויי קבצים ופעילות הרשאות
- לכידת רשומות יומן האירועים של Windows (אבטחה, מערכת, יישום)
- ניטור ביצוע PowerShell וסקריפטים
- נרמול נתוני אירועים בזמן אמת
- הצפנת כל אירוע מיד לפני הכתיבה

מאפיינים:
- ~57 MB זיכרון RAM, ~0.1% מעבד
- שירות Windows שקט
- לחלוטין לא מקוון — שום דבר לא עוזב את המכשיר

---

## 2. Nyroxis Intelligence

מנוע הזיהוי והמתאם:
- **27 כללי זיהוי** — דפוסי איומים ידועים באירועים בודדים
- **12 כללי מתאם** — דפוסים בין אירועים קשורים לאורך זמן
- **2 כללי שרשרת** — זיהוי רצפי התקפה רב-שלביים

מאפיינים:
- ~87 MB זיכרון RAM, ~1.8% מעבד
- ניתן להרחבה מלאה — אנשי אבטחה יכולים לכתוב ולפרוס כללים מותאמים אישית בפורמט JSON
- מעלה התראות מיידיות בעת התאמת כללים
- מאחסן ממצאים במסדי נתונים ייעודיים לזיהוי

---

## 3. Nyroxis System Guardian

שומר הפלטפורמה הפועל כיישום מגש המערכת:
- מנטר את Nyroxis Agent ו-Intelligence כל 3 שניות
- מנהל גיבויי מסד נתונים מתוזמנים ולפי דרישה
- מאמת רישיון מבוסס HWID במצב לא מקוון (AES-GCM + HMAC)
- עוצר שירותים אוטומטית אם הרישיון פג
- בודק עדכוני פלטפורמה במרווחים הניתנים להגדרה

מאפיינים:
- ~6.5 MB זיכרון RAM, ~0.1% מעבד
- אימות רישיון לחלוטין לא מקוון
- קריטי לחוסן הפלטפורמה ולשלמות הפורנזית

---

## 4. מסד הנתונים המקומי המאובטח

מסד נתונים SQLite מוגן המכיל:
- יומני אירועים מוצפנים
- ממצאי זיהוי ומתאם
- תוצאות ניתוח בינה מלאכותית/ML
- נתוני קו בסיס התנהגותי
- מטא-נתונים לשחזור ציר הזמן הפורנזי

תכונות אבטחה:
- הצפנת AES-256 במנוחה
- בלוקי אירועים המקושרים בגיבוב לזיהוי חבלה
- נתיבי כתיבה מוגנים
- אימות שלמות בכל קריאה

מסד הנתונים **לעולם אינו עוזב את המכשיר**.

---

## 5. מנוע הבינה המלאכותית/ML המקומי

מנוע זיהוי האנומליות הלא מקוון המוטמע ב-Dashboard:
- Isolation Forest מותאם אישית (100 עצים, 256 דגימות, 8 מאפיינים התנהגותיים)
- סיווג סטטיסטי Z-Score: קריטי / גבוה / בינוני / נמוך
- זיהוי חריגים IQR, ממוצעים נעים, זיהוי קפיצות
- זיהוי מאפיינים תורמים עם ערכי Z-Score
- בניית קו בסיס התנהגותי מקומי

ללא ענן, ללא ספריית ML חיצונית, ללא שיתוף נתונים.

---

## 6. Nyroxis Dashboard

ממשק המשתמש המספק:
- ניטור אירועים בזמן אמת עם חיפוש פורנזי וסינון
- ויזואליזציה של תוצאות זיהוי, מתאם ושרשרת
- ניתוח בינה מלאכותית/ML עם פירוט מאפיינים תורמים
- דיווח — ייצוא PDF/CSV
- ניהול גיבויי מסד נתונים
- הגדרות ובקרת שמירה
- רב-לשוני: אנגלית, צרפתית, גרמנית

כל מה שמוצג נשלף באופן מקומי ממסד הנתונים המאובטח.

---

## סיכום

רכיבי Nyroxis פועלים כמערכת אקולוגית משולבת, פרטית ולא מקוונת — המספקת נראות ברמה ארגונית, זיהוי רב-שכבתי, בינה מלאכותית/ML מקומית וראיות ברמה פורנזית מבלי לחשוף נתוני משתמש כלשהם לענן.
