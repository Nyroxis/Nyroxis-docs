# ארכיטקטורה ברמה גבוהה

ארכיטקטורת Nyroxis מתוכננת לספק אבטחה חזקה, פרטיות מלאה ואוטונומיה לא מקוונת מוחלטת.
סקירה ברמה גבוהה זו מסבירה כיצד כל הרכיבים המרכזיים פועלים יחד תוך שמירה על נתוני המשתמש מוגנים ומוצפנים באופן מקומי.

---

## עקרונות ארכיטקטוניים מרכזיים

### 1. פעולה מקומית מלאה
כל העיבוד — איסוף, זיהוי, ניתוח בינה מלאכותית, אחסון, דיווח — מתרחש על המכשיר. שום דבר לא מועלה או מועבר.

### 2. פרטיות כעיקרון עיצובי
ללא ענן. ללא טלמטריה. ללא ניטור מרחוק. ללא יצירת פרופיל התנהגותי.

### 3. קל ויעיל
מתוכנן לפעול ברציפות על מחשבים ניידים אישיים מבלי לפגוע בפרודוקטיביות היומיומית.

### 4. שלמות פורנזית
יומני אירועים מוצפנים, מקושרים בגיבוב ועמידים בפני חבלה — מתאימים להליכים משפטיים ורגולטוריים.

---

## רכיבים ברמה גבוהה

### 1. Nyroxis Agent
- לוכד אירועי מערכת בזמן אמת ממספר ערוצים
- מנרמל ומצפין באופן מיידי
- מאחסן אירועים מוצפנים במסד הנתונים המקומי
- ~57 MB זיכרון RAM, ~0.1% מעבד

### 2. Nyroxis Intelligence
- מעריך אירועים לפי 27 כללי זיהוי + 12 כללי מתאם + 2 כללי שרשרת
- מעלה התראות מיידיות בעת התאמת כללים
- ניתן להרחבה מלאה על ידי אנשי אבטחה (פורמט כללי JSON)
- ~87 MB זיכרון RAM, ~1.8% מעבד

### 3. Nyroxis System Guardian
- מנטר את Agent ו-Intelligence כל 3 שניות
- מנהל גיבויים ואימות רישיון HWID לא מקוון
- עוצר שירותים אם הרישיון פג
- ~6.5 MB זיכרון RAM, ~0.1% מעבד

### 4. מסד הנתונים המקומי המאובטח
- SQLite עם הצפנת AES-256
- בלוקי אירועים המקושרים בגיבוב לזיהוי חבלה
- מאחסן אירועים, ממצאים, תוצאות בינה מלאכותית וקווי בסיס
- לעולם אינו עוזב את המכשיר

### 5. מנוע הבינה המלאכותית/ML המקומי
- זיהוי אנומליות Isolation Forest (100 עצים, 8 מאפיינים)
- Z-Score, IQR, ממוצע נע, זיהוי קפיצות
- פירוט מאפיינים תורמים לאנליסטים
- לחלוטין לא מקוון — ללא היסק בענן

### 6. Nyroxis Dashboard
- נראות בזמן אמת: אירועים, זיהויים, מתאמים, שרשראות, בינה מלאכותית/ML
- חיפוש פורנזי, תרשימים, דיווח (PDF/CSV)
- ניהול גיבויים, הגדרות, רב-לשוני (EN/FR/DE)
- כל הנתונים נשלפים באופן מקומי

---

## שכבות אבטחה

הארכיטקטורה כוללת מספר שכבות הגנה:
- הצפנה בלכידה (AES-256)
- מבני אירועים המקושרים בגיבוב
- נתיבי כתיבה מוגנים
- שומר פלטפורמה לחוסן השירותים
- אימות רישיון לא מקוון
- ללא תקשורת חיצונית מכל סוג

---

## סיכום זרימת הנתונים

```
[ אירועי מערכת ]
        ↓
[ Nyroxis Agent ]          ← איסוף, נרמול, הצפנה
        ↓
[ מסד נתונים מוצפן מקומי ]  ← AES-256, SQLite, מקושר בגיבוב
        ↓
[ Nyroxis Intelligence ]   ← 27 זיהוי + 12 מתאם + 2 כללי שרשרת
        ↓
[ מנוע בינה מלאכותית/ML מקומי ] ← Isolation Forest + ניתוח סטטיסטי
        ↓
[ Nyroxis Dashboard ]      ← נראות, פורנזיקה, דיווח
        ↑
[ Nyroxis System Guardian ] ← מנטר, מגבה, מאמת רישיון
```

---

## סיכום

ארכיטקטורת Nyroxis מספקת אבטחה עוצמתית, פרטית ולא מקוונת על ידי שילוב ארבעה רכיבים מרכזיים — Agent, Intelligence, System Guardian ו-Dashboard — הפועלים יחד עם בינה מלאכותית/ML מקומית ואחסון ברמה פורנזית, לחלוטין ללא חשיפה לענן.
