## 🔒 What is Nyroxis?

Nyroxis is a modern cybersecurity platform focusing on **privacy**, **local protection**, and **lightweight design**.

### 💻 Built to Solve a Growing Problem
Today’s personal and unmanaged devices are the weakest link in digital security:

- No visibility into system activity
- Delayed detection of abnormal behavior
- Cloud-based tools that compromise privacy
- No unified local monitoring

Nyroxis fixes this by providing:

- 🧠 **Local behavioral AI/ML detection** — runs fully on-device
- ☁️ **Optional AI Copilot** — opt-in, EU-hosted cloud analysis of individual alerts (off by default)
- 🔒 **Encrypted local storage**
- 📊 **Clear dashboards and charts**
- 🚫 **Offline-first security**
- 🛡️ **A lightweight agent that protects in real time**

---

## 🧩 Platform Components

Nyroxis consists of four core components:

### 1) 🛰️ **Nyroxis Agent**
A lightweight event collector that monitors system behavior, logs activities, and provides real-time security insight — all stored **locally** and **encrypted**.

### 2) 🧠 **Nyroxis Intelligence**
The detection engine — evaluates events across three layers (detection, correlation, chain) and raises alerts in real time.

### 3) 🛡️ **Nyroxis System Guardian**
A silent system-tray guardian that monitors services, manages backups, validates the offline license, and checks for updates.

### 4) 📊 **Nyroxis Dashboard**
A clean and intuitive user interface for reviewing system events, detections, correlations, chains, charts, and rule-based alerts. It also hosts the local AI/ML engine and the optional AI Copilot.

The core platform runs **on the device**. The only optional exception is the AI Copilot (opt-in, off by default).
